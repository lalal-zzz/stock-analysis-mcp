# 强势板块评分研究归档

本目录提交的是两轮**局部行业样本**实验代码、统计和失败结论，不是全行业评分功能。**完整申万一级、二级、三级行业目录、父子关系、全量成分股及历史归属仍未完成。此前结果不能推广到全行业。**

## 已完成

- v1：新浪局部行业成分、腾讯日线、归档新浪复权因子；线性/log/平方/衰减模型比较，统一缺失样本掩码。
- v2：778只股票的4069083条新浪历史记录；与腾讯497920条重叠收盘价一致；23行业2020～2023逐年回溯，946个有效测试日期。
- 数学、标签时序、历史制度变化和数据因果测试。
- v2所有模型平均IC的95%区间均覆盖零。没有自动启用生产规则。

完整结果见[v1报告](v1/results/report.md)、[v2报告](v2/results/report.md)和各自CSV/JSON。报告中的图片、Parquet及原始行情保存在研究工作区，未提交至Git；图片缺失不影响统计表。

## 运行

安装项目依赖及`pytest pyarrow matplotlib scipy`。在仓库根目录执行：

```bash
pytest -q research/sector_strength/v1/test_research.py research/sector_strength/v2/test_validate.py
```

大体积原始JS、行情缓存、复权因子、Parquet与压缩包不进入Git。脚本默认以各自目录为数据根目录，也支持`SECTOR_V1_ROOT`和`SECTOR_V2_ROOT`指向原有研究数据目录。

```bash
SECTOR_V1_ROOT=/path/to/sector-research SECTOR_V2_ROOT=/path/to/sector-validation-v2 python research/sector_strength/v2/validate.py
```

重新计算需要已有的原始数据/缓存和归档复权因子；仅克隆Git仓库不会获得全量行情。v1/adapter.patch记录了本轮研究副本的代理适配与腾讯备用接口，不会自动修改生产网络行为。采集前设置`EASTMONEY_NET_PATCH=0`、`EASTMONEY_VERIFY_TLS=1`，在需代理环境下按补丁适配；保留系统代理及TLS校验。`collect_history.py`使用已安装AKShare本地解码器解析新浪压缩数据，非执行服务端JS。

## 限制

现存成分股回看有幸存者/归属偏差；涨停字段为规则候选，缺少完整历史ST与交易所参考涨停价；收益为重叠事件统计，未包含费用与可成交约束。v2原计划训练从2017年开始，但覆盖门槛使实际最早训练信号为2018-05-30，首折样本有限。
